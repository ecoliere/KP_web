# Personal Web Page

Веб-приложение социальной сети: регистрация и авторизация, личный профиль, поиск пользователей по имени и увлечениям, система друзей, чат с шифрованием сообщений.

Стек: Python 3.13, Flask, MySQL 8.0, HTML/CSS/JavaScript (ES6+), SocketIO, Jinja2.

Архитектура: клиент-серверная, обмен данными через REST API в формате JSON. Серверная логика сосредоточена в app.py. База данных нормализована (3NF): таблицы users, hobbies, user_hobbies, friendships, posts, chats, chat_users, messages.

Безопасность: хеширование паролей (bcrypt), CSRF-защита, параметризованные SQL-запросы, шифрование сообщений чата (Fernet).
Требуется предварительно созданная база данных MySQL с настройками подключения в конфигурации проекта.
Курсовой проект веб-программирование (май 2025)
